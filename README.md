# LilyPond テンプレート生成ツール

ブラウザ上で LilyPond の楽譜テンプレートを生成・コンパイル・プレビューできるツールです。
フォルクローレ（アンデス音楽）の楽器を中心に設計されています。

## スクリーンショット

左ペインで設定を入力 → 右ペインにリアルタイムで LilyPond コードが生成されます。
右ペインのコードは直接編集でき、ブラウザ内でコンパイル・SVGプレビューも可能です。

## 機能

- タイトル・作曲者・調性・拍子・テンポを設定
- 楽器を複数追加（プリセットあり）
- セクション（A、B、サビ等）ごとに登場する楽器を制御（空スタッフ非表示対応）
- 右ペインで生成されたコードを直接編集可能（ダーティ状態の警告表示）
- ローカルサーバー経由でコンパイルし、SVGをブラウザ内プレビュー

## 楽器プリセット

### フォルクローレ（アンデス）
Quena / Quena II / Quenacho / Zampoña (Siku) / Tarka / Pinkillo / Charango / Guitarra / Arpa andina / Bombo leguero / Caja / Cajón

### その他
弦楽器・木管・金管・打楽器・鍵盤楽器など標準的なオーケストラ楽器

## 必要なもの

- [LilyPond](https://lilypond.org/) 2.20 以上
- Python 3.x（プレビューサーバー用）

## 使い方

### 1. サーバーを起動

```bash
python3 lilypond-server.py
```

ブラウザが自動で `http://localhost:7890` を開きます。

### 2. ブラウザで直接開く（サーバーなしの場合）

```bash
open lilypond-template.html
```

コンパイル・プレビュー機能は使えませんが、コードの生成とコピーは可能です。

### 3. テンプレートの使い方

1. 左ペインで曲の基本情報を入力
2. 「楽器を追加」でパートを追加
3. 「セクションを追加」で曲の構成を定義（A部、B部など）
4. 各セクションのチェックボックスで登場する楽器を選択
5. 右ペインに生成された `.ly` コードをコピーして使用、またはそのまま編集
6. 「▶ コンパイル」ボタンでブラウザ内プレビュー

## ファイル構成

```
lilypond-template.html   # メインのWebアプリ（単一ファイル）
lilypond-server.py       # ローカルコンパイルサーバー（Python）
```

## LilyPond について

- バージョンはUIで指定可能（デフォルト: 2.20.0）
- `\RemoveEmptyStaves` で未使用スタッフを非表示にするオプションあり
- 複数同種楽器は `quenaA`, `quenaB` のように変数名を自動で区別
- セクションの小節数は各セクションで個別に設定可能
